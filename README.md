# UGC Ad Prompt System 🚀

## 📌 Business Chosen
Mamaearth Ubtan Face Wash (Skincare Brand)

## 🎯 Objective
To build a reusable AI prompt system that generates:
- Hooks
- UGC Scripts
- CTAs
- Captions

## 🧠 Prompt Logic
This system follows a proven ad framework:

Hook → Problem → Solution → Result → CTA

The prompts are designed to:
- sound like real users (UGC style)
- avoid salesy language
- create high-converting ad content

## 🛠 Tools Used
- ChatGPT
- Claude
- Google Gemini
